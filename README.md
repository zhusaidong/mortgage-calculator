# 房贷组合贷计算器

> 一个纯前端、离线可用的房贷计算工具，支持商业贷款、公积金贷款、组合贷款，多方案横向对比，还款明细、图表与报告导出，数据本地存储，深色模式跟随操作系统。基于
> Vue 3 + Vite 构建。

## 🌟 功能特性

- **三种贷款类型**：组合贷款可自由拆分；切到纯商业/纯公积金时自动锁定对应金额并隐藏公积金滑块，选择随配置持久化，切回组合贷款时保留原公积金输入
- **两种还款方式**：等额本息、等额本金，实时切换
- **还款方式对比**：并排展示两种方式的首月/末月月供、支付利息、本息合计、期数与利息差额，并给出适用人群说明
- **智能输入**：
    - 房屋总价 + 首付比例滑块联动，自动算出首付金额与贷款总额
    - 首付比例快捷按钮：15% / 20% / 30% / 40% / 50%
    - 贷款年限快捷按钮：10 / 15 / 20 / 25 / 30 年
    - LPR 加点快捷选项：-60bp / -45bp / -30bp / 0bp / +20bp
- **收入与公积金**：
    - 输入税后月工资、税前月工资、每月公积金缴存额
    - 自动计算公积金冲抵后的实际自付月供
    - 自动计算月供占税后收入比例
    - 按税前收入计算银行审批常用的「偿贷比」，超过 50% 给出提示
- **偿还能力评估**：按「月供占税后」和「银行偿贷比」自动分级，给出舒适 / 偏紧 / 超红线结论
- **反向测算**：输入可承受月供或偿贷比红线，反推可买房价上限及首付、贷款拆分
- **还款明细表**：
    - 年度汇总（每年月供、本金、利息、公积金抵扣、自付、年末剩余本金）
    - 月度明细按 24 期分页，展示每期月供构成与剩余本金
    - 明细可一键导出 CSV
- **图表可视化**：纯手写 SVG，无图表库依赖——本息结构环形图、剩余本金走势面积图、两种还款方式的月供走势对比
- **方案对比**：
    - 一键加入对比列表，多方案横向比较
    - 横屏查看模式：转置竖表格（项目在左，方案在右）
    - 自动标记总利息、月供、自付三项指标的最优方案
    - 支持导出 CSV 文件
- **报告导出**：
    - 「打印 / PDF」生成 A4 报告版式：测算参数、核心指标、两种还款方式对比、全部年度明细，浏览器打印对话框可直接另存为 PDF
    - 「导出长图」生成 1080px 宽的 PNG 长图，便于分享与留档
- **数据持久化**：所有配置与对比列表自动保存到浏览器 `localStorage`，刷新不丢失
- **按需测算**：首次访问不显示结果，录入任一参数后才开始测算；有本地存档时直接恢复上次结果
- **深色模式**：跟随操作系统外观自动切换，无手动开关，系统主题变化实时生效
- **PWA 支持**：可添加到手机主屏幕，全屏独立运行，离线可用
- **响应式布局**：桌面左右分栏、移动端上下堆叠，触摸友好

## 🧱 技术栈

| 项   | 选择                                                          |
|------|---------------------------------------------------------------|
| 框架 | Vue 3.5（Composition API + `<script setup>`）                 |

| PWA  | vite-plugin-pwa（Workbox 生成 Service Worker）                |
| 样式 | 原生 CSS + 设计令牌（CSS 变量），深色模式跟随系统，无 UI 框架 |

## 🚀 快速开始

```bash

npm install

# 开发（热更新）
npm run dev          # http://localhost:5173

# 生产构建，产物在 dist/
npm run build

# 单文件构建，产物 dist-single/index.html（JS/CSS 全部内联）
```

## ☁️ 部署

仓库已内置 GitHub Actions（`.github/workflows/static.yml`）：

```
push 到 master → npm ci → npm run build → 上传 dist/ 到 GitHub Pages
```

部署到其他静态托管平台时， **上传 `dist/` 目录**即可（腾讯云 EdgeOne Pages、CloudBase、Vercel、Netlify 等）。

`vite.config.js` 中 `base: './'` 使用相对路径，因此部署到任意子路径（例如 `https://example.com/mortgage/` ）都能正常加载资源。

## 🧮 计算说明

- **等额本息**：每月还款额固定，月供 = 本金 × 月利率 × (1+月利率)^期数 / [(1+月利率)^期数 - 1]
- **等额本金**：每月本金固定，利息逐月递减，首月月供最高，末月月供最低
- **公积金冲抵模型**：优先冲抵公积金贷款月供，剩余部分冲抵商业贷款月供；若公积金月缴存额大于总月供，则全部覆盖
- **利率口径**：商贷利率 = LPR + 加点（bp 换算为百分点，1bp = 0.01%）
- **银行偿贷比**：月供（公积金 + 商贷）÷ 税前月收入，银行审批常以 50% 作为参考红线
- **反向测算**：以「月供随房价单调递增」为前提，用二分法反解满足目标月供的房价上限；测算上限定为 1 亿元
- **还款明细**：逐月摊销。等额本息每月月供固定、末月吸收浮点残差；等额本金每月本金固定、末月结清剩余本金。公积金抵扣按「先公积金后商贷」逐月计算，年度汇总按
  12 期切片
- **贷款类型**：`combo` 按用户输入的公积金金额拆分；`commercial` 强制公积金为 0、全部商贷；`fund`
  强制全部公积金。纯商贷/纯公积金模式忽略公积金金额输入，切回组合贷款时恢复原值

计算引擎位于 `src/core/calc.js` 与 `src/core/amortize.js`，均为纯函数、无 DOM 依赖，共 75 条单元测试覆盖（calc 26 / amortize
14 / loanType 11 / storage 13 / report 11，含 0 利率、0 本金等边界）。

## ⚠️ 已知限制

- 公积金冲抵为简化模型，未区分按月冲/按年冲/异地使用等地方政策。
- 纯公积金模式全部按公积金贷款测算，不校验当地公积金中心的额度上限、缴存年限等准入条件。
- 打印版报告的分页由浏览器决定，长表格可能跨页。
